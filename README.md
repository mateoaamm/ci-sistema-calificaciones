# Sistema de Calificaciones Académicas

Proyecto desarrollado para demostrar un proceso de Integración Continua utilizando Jenkins.

## Tecnologías

- Java 21
- Maven
- JUnit 5
- Git
- GitHub
- Jenkins

## Funcionalidades

El sistema permite:

- Calcular el promedio de notas.
- Obtener la nota máxima.
- Obtener la nota mínima.
- Determinar si un estudiante aprueba o reprueba.
- Validar que las notas estén entre 0.0 y 5.0.

## Pruebas automatizadas

El proyecto cuenta con pruebas unitarias desarrolladas con JUnit.

Ejecutar:

mvn clean test
